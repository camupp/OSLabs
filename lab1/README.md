# Лабораторная работа №1 — Операционные системы

**Вариант 12**

Программа демонстрирует межпроцессное взаимодействие в Linux с использованием системных вызовов `fork()`, `pipe()`, `dup2()`, `execl()`, `read()`, `write()` и `waitpid()`.

## Архитектура программы

```text
parent -> child1 -> child2 -> parent
```

- `child1` переводит входную строку в верхний регистр.
- `child2` удаляет повторяющиеся пробелы.

Пример:

```text
hello     world
```

Результат:

```text
HELLO WORLD
```

## Структура проекта

```text
.
├── parent.cpp
├── child1.cpp
├── child2.cpp
├── io_utils.cpp
├── io_utils.h
└── Makefile
```

## Сборка и запуск

Скомпилировать проект:

```bash
make
```

Скомпилировать и сразу запустить:

```bash
make run
```

Запустить вручную после сборки:

```bash
./parent
```

После запуска можно вводить строки в терминал.

Пример:

```text
hello      my   friend
THIS   IS    TEST
```

Результат:

```text
HELLO MY FRIEND
THIS IS TEST
```

Для завершения ввода используется EOF:

```text
Ctrl + D
```

## Очистка проекта

Удалить скомпилированные файлы:

```bash
make clean
```

Полностью пересобрать проект:

```bash
make rebuild
```

## Требования

- Linux или другая POSIX-совместимая система
- `g++`
- `make`
